# LifeAI — دستیار هوشمند زندگی

LifeAI یک برنامه وب واکنش‌گرا و نصب‌پذیر (PWA) برای استفاده در رایانه و Android است. این نسخه، پایه اجرایی برنامه را با ابزارهای روزمره و اتصال اختیاری به سرویس هوش مصنوعی فراهم می‌کند.

## امکانات نسخه رنگی LifeAI

### برنامه‌ریزی و مدیریت روزانه
- داشبورد شخصی با خوشامدگویی، تاریخ روز، خلاصه کارها، عادت‌ها، زمان تمرکز و موجودی ماهانه
- تقویم ماهانه تعاملی و ثبت قرارها و رویدادهای هر روز
- فهرست کارها با اولویت، مهلت، جست‌وجو و وضعیت انجام‌شده
- عادت‌های روزانه با ثبت روزانه و شمارش روزهای پیوسته
- ثبت حال‌وهوای روزانه با انتخاب شکلک
- تایمر تمرکز ۱۵، ۲۵، ۴۵ و ۶۰ دقیقه‌ای با ثبت جلسه‌های تکمیل‌شده

### یادداشت و امور مالی
- دفتر یادداشت با جست‌وجو، برچسب و سنجاق‌کردن یادداشت‌های مهم
- ثبت درآمد و هزینه با تاریخ و دسته‌بندی
- خلاصه مالی ماهانه و تنظیم بودجه برای دسته‌های مختلف هزینه
- نمایش میزان خرج‌شده و مانده هر بودجه

### جعبه ابزار و اسناد
- ماشین‌حساب با صفحه‌کلید دکمه‌ای
- تبدیل واحد طول، وزن و دما
- محاسبه درصد و تخفیف
- ابزار شمارش کلمات و نویسه‌ها و تبدیل حروف بزرگ و کوچک
- اسکنر همراه: انتخاب فایل یا عکس‌گرفتن با دوربین، پیش‌نمایش و ذخیره محلی تصویر/PDF در دستگاه
- امکان چاپ یا ذخیره صفحه به PDF از طریق مرورگر
- خروجی و بازیابی نسخه پشتیبان JSON برای اطلاعات اصلی برنامه

### ظاهر و دسترسی
- طراحی شاد با رنگ‌های روشن، کارت‌های رنگی، انیمیشن‌های ظریف و چیدمان واکنش‌گرا
- فارسی، انگلیسی و عربی با پشتیبانی راست‌به‌چپ و چپ‌به‌راست
- پوسته رنگی، روشن و تیره
- منوی کناری برای رایانه و منوی پایین صفحه برای گوشی
- نصب‌پذیر روی Android از طریق Chrome و قابل استفاده محدود آفلاین پس از بارگذاری اولیه

### دستیار هوش مصنوعی
- حالت‌های گفت‌وگوی عمومی، ترجمه، نگارش، آموزش و برنامه‌ریزی
- ارتباط از طریق سرور Node.js جداگانه و Responses API
- کلید API فقط در محیط امن سرور نگهداری می‌شود و داخل فایل‌های مرورگر قرار نمی‌گیرد

## مواردی که هنوز آماده نیستند

- اسکنر فعلاً فایل را ذخیره و پیش‌نمایش می‌کند؛ OCR، تشخیص خودکار متن، اصلاح پرسپکتیو و ساخت PDF جست‌وجوپذیر هنوز پیاده‌سازی نشده‌اند.
- تایمر و اعلان‌های مرورگر در زمان بازبودن برنامه کار می‌کنند؛ یادآور پوش در پس‌زمینه و همگام‌سازی تقویم گوشی فعال نیست.
- اطلاعات برنامه روی همان دستگاه و مرورگر ذخیره می‌شود و به‌طور خودکار بین گوشی و رایانه همگام نمی‌شود.
- حساب کاربری، فضای ابری، ایمیل، پیام‌رسانی، پرداخت و اشتراک هنوز فعال نیستند.
- دستیار آنلاین تا زمان استقرار سرور و تنظیم کلید API کار نمی‌کند.
- APK فعلی نسخه debug برای آزمایش است؛ نسخه release امضاشده برای انتشار عمومی در Google Play هنوز آماده نشده است.

## انتشار وب در GitHub Pages

فایل گردش‌کار انتشار خودکار در مسیر `.github/workflows/deploy-pages.yml` قرار دارد.

1. در مخزن GitHub به **Settings → Pages** بروید.
2. در بخش **Build and deployment**، گزینه **GitHub Actions** را انتخاب کنید.
3. به بخش **Actions** بروید و منتظر تکمیل گردش‌کار `Deploy LifeAI to GitHub Pages` بمانید.

نشانی سایت پس از انتشار:

`https://mahdimokhtari39161-svg.github.io/LifeAI/`

## نصب روی Android

پس از انتشار موفق سایت، نشانی بالا را با Chrome گوشی باز کنید. از منوی Chrome گزینه **Install app** یا **Add to Home screen** را انتخاب کنید. این کار نسخه نصب‌پذیر وب را روی گوشی اضافه می‌کند و APK مستقل نیست.

## ساخت APK برای Android

گردش‌کار `Build LifeAI Android APK` برای ساخت نسخه آزمایشی نصب‌پذیر Android اضافه شده است. پس از اجرای موفق آن:

1. در مخزن به **Actions** بروید.
2. گردش‌کار **Build LifeAI Android APK** را باز کنید.
3. آخرین اجرای موفق را انتخاب کنید.
4. در بخش **Artifacts** فایل `LifeAI-Android-debug` را دریافت کنید و APK داخل آن را روی گوشی نصب کنید. این خروجی نسخه debug برای آزمایش است، نه نسخه انتشار فروشگاه Google Play.

نسخه Android فایل‌های برنامه را داخل APK نگه می‌دارد و برای ابزارهای محلی به اتصال دائمی اینترنت نیاز ندارد. دستیار AI همچنان به سرور پشتیبان و اینترنت احتیاج دارد.

## راه‌اندازی سرور هوش مصنوعی

GitHub Pages فقط فایل‌های وب را میزبانی می‌کند و اجرای Node.js را انجام نمی‌دهد. برای فعال‌کردن دستیار هوش مصنوعی:

1. پوشه `backend/` را روی یک میزبان Node.js نسخه 20 یا بالاتر مستقر کنید.
2. متغیرهای محیطی سرور را تنظیم کنید:
   - `OPENAI_API_KEY`: کلید خصوصی API که فقط باید در تنظیمات امن سرور قرار گیرد.
   - `OPENAI_MODEL`: شناسه مدلی که در پروژه API شما فعال است؛ پیش‌فرض نمونه `gpt-6-luna` است.
   - `APP_ORIGIN`: مبدأهای مجاز که با ویرگول از هم جدا می‌شوند؛ برای وب و Android این دو مقدار را وارد کنید: `https://mahdimokhtari39161-svg.github.io,https://appassets.androidplatform.net`.
   - `PORT`: در صورت نیاز میزبان مقدار آن را تعیین می‌کند؛ مقدار پیش‌فرض 8787 است.
3. دستور اجرا: `npm start`
4. مسیر `/health` را بررسی کنید تا وضعیت سرویس نمایش داده شود.
5. در LifeAI به **ابزارها → تنظیمات** بروید و آدرس اصلی سرور را وارد کنید؛ `/api/ai` را به انتهای آدرس اضافه نکنید.

**کلید API را هرگز در فایل‌های HTML یا JavaScript، مخزن GitHub یا کد سمت مرورگر قرار ندهید.** فایل `.env` نیز نباید در Git بارگذاری شود؛ `.gitignore` آن را مستثنا کرده است.

### اجرای محلی سرور

```bash
cd backend
cp .env.example .env
# کلید واقعی و APP_ORIGIN دقیق را فقط در فایل محلی .env تنظیم کنید
npm start
```

برای آزمایش رابط وب، پوشه اصلی را با یک وب‌سرور محلی اجرا کنید؛ فایل `index.html` را مستقیماً با نشانی `file://` باز نکنید.
